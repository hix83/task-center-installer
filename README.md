# Task Center Installer

Небольшой установщик и ярлык **Automated tasks / Task Center** для Xiaomi HyperOS.
Подбирает компонент по **подписанному обновляемому каталогу**, скачивает APK и передаёт его системному установщику Android.

**[Скачать 3.0](https://github.com/hix83/task-center-installer/releases/tag/v3.0.0)** · [Инструкция](docs/INSTALL-RU.txt) · [Каталог совместимости](catalog/catalog.json) · [Apache 2.0](LICENSE)

Независимый проект, не продукт Xiaomi. Сборка пробная; совместимость с моделями и прошивками, отсутствующими в каталоге, не заявляется.

## Как работает

1. Если новый экран Automated tasks уже установлен и подпись «Безопасности» совпадает с Xiaomi, приложение предлагает открыть его и добавить ярлык.
2. Иначе сопоставляет **код устройства, модель, Android API, точную сборку HyperOS и установленный versionCode «Безопасности»** с каталогом. Нет подтверждённой записи — нет установки.
3. **«Обновить каталог»** загружает новую подписанную версию с GitHub. Без сети остаётся локальная проверенная копия. При ошибке подписи старая копия сохраняется.
4. По нажатию **«Скачать и установить»** скачивает выбранный APK, проверяет размер, SHA-256, пакет, версию и сертификат Xiaomi. Перед установкой повторно проверяет исходную версию на телефоне.
5. Android показывает обычное подтверждение обновления. После завершения пользователь возвращается в Task Center.

Root и ADB пользователю не нужны. Для загрузки нужны интернет и доступ к GitHub. Первое открытие 3.0 показывает экран настройки даже если компонент уже установлен. После нажатия «Открыть Task Center» последующие запуски работают как прямой ярлык. По долгому нажатию на значок доступен пункт **«Настройка и откат»**.

## Поддержка устройств

Правила точные: совпадения только Android 16 или семейства Xiaomi 14 недостаточно.

| Устройство и прошивка | Исходная «Безопасность» | Подтверждено |
|---|---|---|
| Xiaomi 15T Pro (`klimt`), Android 17, `OS3.0.336.0.XOSRUXM` | 12.7.5 / 40001275 | Переход на 12.8.3 через системный установщик из мастера 2.1, открытие Task Center |
| Xiaomi 17T Pro (`warhol`), Android 16, `OS3.0.306.0.WPSRUXM` | 12.6.1 / 40001261 | Установка 12.8.3 через ADB и открытие Task Center; установка через мастер пока не подтверждена |
| Xiaomi 14 / другие модели и сборки | — | Нет подтверждённых правил; автоматическая установка блокируется |

На неподдерживаемом телефоне нажмите **«Скопировать сведения об устройстве»** и приложите их к GitHub Issue. В сведения входят модель, код устройства, Android, сборка, версия «Безопасности» и каталога. Серийные номера и аккаунты не включаются. Новый вариант добавляется после проверки, а не по предположению.

Выполнение сценариев и длительная стабильность не проверены. Поддержка открытия экрана не означает подтверждение всех функций «Безопасности».

## Установка и откат

Скачайте APK релиза, установите и откройте. Если нужна установка компонента: разрешите установку из Task Center, вернитесь, нажмите **«Скачать и установить»** и подтвердите обновление Android. Если значок не появляется автоматически, на экране готовности есть **«Добавить ярлык на рабочий стол»**; рабочий стол может запросить подтверждение.

Обновляется **всё приложение «Безопасность»**, возможны изменение языка и несовместимость с другими функциями. Разрешение на установку из источника не заменяет системное подтверждение обновления.

Откат: долгое нажатие на значок → **Настройка и откат → Открыть настройки для отката → Удалить обновления / Uninstall updates**. Вернётся версия **из прошивки**, не обязательно версия перед установкой. Настройки и задачи могут сброситься. Если этой кнопки нет, остановитесь. Не удаляйте системное приложение и не очищайте его данные. Удаление Task Center само по себе не откатывает «Безопасность».

На 15T Pro также проверен откат штатной командой менеджера пакетов Android и последующая установка компонента через APK-мастер. Приложение не запускает эту ADB-команду.

## Каталог и безопасность скачивания

[Формат и обновление каталога](catalog/README.md). Каталог доставляется одним JSON-конвертом с RSA/SHA-256 подписью. Публичный ключ встроен в приложение; приватный не публикуется. Сетевое обновление не может заменить каталог старшей ревизии более старым.

В 3.0 бинарника Xiaomi внутри нет. Он скачивается из отдельного release asset. При смене версии каталога новые правила могут использовать новые проверенные APK без выпуска нового установщика. Неизвестная схема каталога требует обновления приложения.

Скачивание ограничено HTTPS и хостами GitHub, число перенаправлений, размер ответа и время ожидания ограничены. Неполные файлы удаляются. Контрольная сумма и фиксированная подпись Xiaomi проверяются до передачи APK установщику. Доступен отказ от скачивания. Файлы лежат в закрытом cache приложения; `ApkProvider` выдаёт только APK с временным разрешением чтения.

Установщик запрашивает `INTERNET` и `REQUEST_INSTALL_PACKAGES`. Нет аналитики, рекламы или загрузки диагностических сведений на сервер. GitHub при сетевом запросе видит обычные сетевые метаданные, включая IP-адрес. Отдельное приложение Xiaomi имеет собственные разрешения и поведение.

## Сборка

Python 3.9+, JDK (проверено с 23), Android SDK Platform 35 и Build Tools 36.0.0. Gradle и внешние Android-библиотеки не требуются. Скрипты проверены на macOS.

```sh
mkdir -p .local
keytool -genkeypair -keystore .local/release.jks -alias launcher \
  -keyalg RSA -keysize 3072 -validity 10000 -dname "CN=TaskCenterLocal"
export ANDROID_SDK_ROOT="/path/to/Android/sdk"
# Задайте TASK_CENTER_STORE_PASS безопасным способом в вашей оболочке.
python3 scripts/build.py --keystore .local/release.jks
```

При отдельном пароле ключа используйте `TASK_CENTER_KEY_PASS`. Результат: `build/Task-Center-Installer-3.0.apk` и `build/SHA256SUMS.txt`. Нужен только подписанный каталог из исходников — скачивать Xiaomi APK для сборки не требуется. Личная сборка с другим ключом не обновит официальный релиз проекта поверх него. Храните свой ключ отдельно от Git.

## Проверки разработки

```sh
mkdir -p build/policy-tests
javac -d build/policy-tests app/src/local/taskcenter/launcher/CatalogPolicy.java tests/CatalogPolicyTest.java
java -cp build/policy-tests local.taskcenter.launcher.CatalogPolicyTest
```

9 сценариев выбора: подтверждённая конфигурация, неизвестная модель, другая версия Android/прошивки/исходного пакета, запрет понижения, выбор новейшего подтверждённого кандидата, другой пакет.

Тесты на явно выбранном устройстве (приложение должно быть установлено и подписано тем же ключом):

```sh
python3 scripts/device_tests.py --serial DEVICE_SERIAL --sdk "$ANDROID_SDK_ROOT" \
  --keystore .local/release.jks --network
```

Сетевой тест скачивает около 70 МБ, проверяет APK и удаляет тестовый файл; «Безопасность» не устанавливает. Проверяет реальную Android-проверку каталога, отказ при подмене подписи, допустимые URL, выбор записи и скачивание/хеш/пакет/версию/сертификат. Тестовый APK устанавливается временно и удаляется после запуска. В релиз он не входит.
