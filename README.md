# Task Center Installer

Русскоязычный офлайн-установщик и ярлык **Automated tasks / Task Center** для Xiaomi с HyperOS.

**[Скачать APK](https://github.com/hix83/task-center-installer/releases/tag/v2.1.0)** · [Инструкция](docs/INSTALL-RU.txt) · [Apache 2.0](LICENSE)

Это независимый проект, не официальный продукт Xiaomi. **Пробная сборка:** полный сценарий первоначальной установки через мастер ещё не проверен на телефоне с глобальной «Безопасностью».

## Что делает

- Проверяет установленную «Безопасность», её подпись и номер версии.
- Предлагает установить встроенный китайский APK `12.8.3-260831.0.1` через стандартный установщик Android.
- После настройки значок **Task Center** напрямую открывает `com.miui.autotask.activity.TaskManagerActivity`.
- По долгому нажатию на значок доступен пункт **«Настройка и откат»**.
- Для отката открывает карточку «Безопасности», где пользователь сам подтверждает **«Удалить обновления»**.

Root, ADB и интернет для обычной установки не нужны. Android требует разрешение на установку из Task Center и подтверждение обновления. Автоматического снятия этих ограничений нет.

## Установка

1. Скачайте `Task-Center-Installer-2.1.apk` из **Releases** и установите на телефон.
2. Откройте **Task Center**.
3. Если появился мастер, нажмите **«Разрешить установку»**, включите разрешение и вернитесь назад.
4. Нажмите **«Установить компонент»**, подтвердите обновление «Безопасности».
5. Вернитесь в Task Center и откройте автоматизации.

Если компонент уже есть, приложение сразу открывает его. В режиме рабочего стола со списком приложений перенесите значок Task Center на рабочий стол вручную.

## Что важно знать

Обновляется **всё приложение «Безопасность»**, а не только Task Center. Интерфейс может стать английским; возможна несовместимость с другими функциями и моделями. Проверка подписи и версии не гарантирует совместимость с конкретным устройством. Более новая «Безопасность» не понижается.

При откате удаляются обновления «Безопасности» и возвращается **версия из прошивки**, не обязательно версия перед установкой. Настройки и задачи могут сброситься. Если кнопки **«Удалить обновления»** нет, остановитесь. **Не удаляйте системное приложение и не очищайте его данные.** Удаление самого Task Center не откатывает «Безопасность».

## Сборка из исходников

Нужны Python 3.9+, JDK (проверено с JDK 23), Android SDK Platform 35 и Build Tools 36.0.0. Gradle и внешние библиотеки приложению не нужны. Скрипт проверен на macOS; другие ОС пока не проверены.

1. Получите **точный оригинальный** Xiaomi Security APK, указанный в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), и сохраните в `third_party/security.apk`. В Git его нет. Скрипт проверит SHA-256, подпись и версию.
2. Создайте личный ключ подписи (пароль вводится интерактивно):

```sh
mkdir -p .local
keytool -genkeypair -keystore .local/release.jks -alias launcher \
  -keyalg RSA -keysize 3072 -validity 10000 -dname "CN=TaskCenterLocal"
```

3. Укажите путь SDK и передайте пароль через переменную окружения. Не добавляйте ключ или пароль в Git:

```sh
export ANDROID_SDK_ROOT="/path/to/Android/sdk"
# Задайте TASK_CENTER_STORE_PASS безопасным способом в вашей оболочке.
python3 scripts/build.py --keystore .local/release.jks
```

При отдельном пароле ключа используйте `TASK_CENTER_KEY_PASS`. Для другого расположения payload используйте `--payload /path/to/security.apk`. Итог: `build/Task-Center-Installer-2.1.apk` и `build/SHA256SUMS.txt`.

Личная сборка будет иметь вашу подпись и не установится поверх релиза с другой подписью. Ключ релизов не публикуется. Сохраните собственный ключ для последующих обновлений.

## Архитектура и приватность

`MainActivity` проверяет доступность нового экрана, показывает мастер и открывает системный установщик. `ApkProvider` предоставляет только один файл APK через временное разрешение чтения URI; запись запрещена, provider не экспортирован. Обновление не начинается без нажатия пользователя.

Единственное запрашиваемое разрешение установщика — `REQUEST_INSTALL_PACKAGES`. Нет аналитики, рекламы, сетевого разрешения, доступа к контактам или сообщениям. Это описание относится к **нашему установщику**; отдельное системное приложение Xiaomi имеет собственные разрешения и поведение.
