# Обновление каталога

`catalog.json` — читаемый исходник. Приложение загружает **только** `catalog.signed.json` с ветки `main`, проверяя подпись встроенным публичным ключом. `app/assets/catalog.signed.json` — резервная копия для новой установки без сети.

## Правило допуска

Каждая запись содержит пакет, версию, URL отдельного APK в GitHub Releases, SHA-256, точный размер и список правил. Каждое правило требует точного совпадения:

- `device`: `Build.DEVICE`;
- `model`: `Build.MODEL`;
- `sdk`: `Build.VERSION.SDK_INT`;
- `incremental`: `Build.VERSION.INCREMENTAL`;
- `fromVersionCodes`: список подтверждённых исходных версий «Безопасности».

`evidence` отображается пользователю: указывайте отдельно установку через ADB или системный установщик, открытие экрана, выполнение сценариев. Не добавляйте модель только потому, что у неё тот же Android. Wildcard-правил нет. Кандидат младше установленной версии запрещён независимо от правила.

## Порядок выпуска

1. Получить APK, проверить `apksigner verify --print-certs`, сравнить сертификат с закреплённым сертификатом Xiaomi.
2. Проверить устройство и сценарий установки; записать точные модель/сборку/исходный versionCode. Не публиковать серийные номера и личные данные.
3. Загрузить APK отдельным asset в релиз и убедиться в доступности ссылки. Дать ссылку вида `https://github.com/hix83/task-center-installer/releases/download/TAG/FILE.apk`.
4. Добавить запись и увеличить `revision`. Для удаления ошибочного правила тоже увеличивать ревизию. Формат `schema` пока равен 1.
5. Подписать каталог приватным ключом, соответствующим `CatalogKey.PUBLIC_KEY`:

```sh
python3 scripts/sign_catalog.py --key /secure/path/catalog-private.pem
```

6. Проверить diff и тесты, затем опубликовать `catalog.json`, `catalog.signed.json` и резервную копию в assets. Пользователь нажимает «Обновить каталог»; новый APK установщика для обновления правил не нужен.

Приватный ключ находится вне Git и должен иметь отдельную резервную копию. `.local/` игнорируется Git. Утрата ключа потребует нового APK с новым доверенным публичным ключом. Ключ каталога и Android-ключ подписи приложения — разные ключи.

Хеш не заменяет проверку сертификата: приложение проверяет оба. Подписанный каталог не является доказательством полной совместимости — в правилах должны быть фактические результаты тестирования.

## Наблюдаемые исходные версии

Необязательное поле `observedSources` хранит версии, о которых сообщили пользователи, их источник и статус исследования. Оно **не даёт разрешения на установку**. Клиент 3.0 игнорирует его при выборе. Список и недостающие данные: [SOURCE-VERSIONS.md](SOURCE-VERSIONS.md). Это позволяет фиксировать запросы без выдуманных model/versionCode и без ложного объявления совместимости.
