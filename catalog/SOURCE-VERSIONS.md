## Что уже подготовлено

Китайский компонент `12.8.3-260831.0.1` доступен отдельным файлом с проверенными подписью, размером и SHA-256. Переход с глобальной 12.6.1 ранее проверен на Xiaomi 17T Pro через ADB. Это кандидат для проверки на других моделях с 12.6.1, а не доказательство совместимости с ними.

## Для добавления работающего правила

Получить модель/код устройства, API Android, полную сборку HyperOS и точный versionCode исходного приложения; проверить подпись и установку выбранного компонента на этой конфигурации. Указать отдельно результат установки через обычный мастер и открытие/выполнение задач. После проверки добавить точное правило в `releases[].rules`, увеличить ревизию и подписать каталог.

Номера versionCode не выводятся из строки версии. Поддержка Android 16 не подменяет проверку модели и прошивки. Скриншоты не публикуются в репозитории.
