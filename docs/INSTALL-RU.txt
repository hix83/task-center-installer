TASK CENTER 3.2 — УСТАНОВКА И ОТКАТ

1. Установите Task-Center-Installer-3.2.apk поверх предыдущего Task Center.
2. Если автоматизации уже доступны, нажмите «Открыть Task Center» или «Добавить ярлык на рабочий стол».
3. Для Xiaomi 14 с Android 16 и «Безопасностью» 12.6.1 нажмите «Скачать APK для ручной установки», прочитайте предупреждение. Нужен интернет.
4. После проверки файла откроется системное окно сохранения. Выберите папку «Загрузки» и сохраните Security-Xiaomi-12.8.3.apk.
5. Самостоятельно откройте штатный «Проводник» Xiaomi → «Загрузки» → сохранённый APK. Подтвердите обновление. Если файл сохранили в другую папку, откройте её.
6. Вернитесь в Task Center. Приложение повторно проверит наличие экрана автоматизаций.

Для других проверенных устройств доступна установка через системное подтверждение. Если HyperOS запретит нашему приложению обновление, мастер предложит сохранить проверенный APK для ручной установки. Если кэш удалён системой, потребуется повторное скачивание.

Сохранение файла не означает, что компонент установлен. Отчёт можно показать или скопировать отдельными кнопками. Никакие сведения автоматически не отправляются.

Обновляется вся «Безопасность» до китайской версии: возможны изменения языка, настроек и других функций. Ручная установка и открытие Task Center на присланном Xiaomi 14 подтверждены; выполнение задач и новый диалог сохранения 3.2 ещё не проверены на телефоне.

ОТКАТ
Удерживайте значок Task Center → «Настройка и откат» → «Открыть настройки для отката». В карточке «Безопасности» выберите «Удалить обновления» / Uninstall updates и прочитайте системное подтверждение. Вернётся версия из прошивки; настройки и задачи могут сброситься. Удаление самого Task Center не откатывает компонент.

Наш код лицензирован Apache 2.0. APK Xiaomi не входит в эту лицензию.
