# Task Center 3.2 — установка Automated tasks на Xiaomi

Task Center помогает установить компонент «Безопасность» с экраном Automated tasks, открыть автоматизации и добавить ярлык. Это независимый проект, не приложение Xiaomi. Root и подключение к компьютеру для описанного ниже сценария не требуются.

## Что исправлено

На Xiaomi 14 HyperOS отклонял обновление системной «Безопасности» из нашего приложения:

```text
INSTALL_FAILED_HYPEROS_ISOLATION_VIOLATION:
local.taskcenter.launcher not allow to install com.miui.securitycenter
```

Это ограничение источника установки. Тот же компонент, открытый отдельно, пользователь успешно установил; экран Automated tasks затем открылся. По скриншотам нельзя точно определить приложение, из которого была запущена успешная установка.

В версии 3.2:

- Для Xiaomi 14 `23127PN0CG`, Android 16, с Security `12.6.1-260608.1.1` сразу предлагается ручная установка.
- При такой блокировке на других устройствах мастер объясняет причину и предлагает сохранить уже скачанный APK, если он остался в кэше.
- Перед сохранением повторно проверяются SHA-256, пакет, сертификат Xiaomi, версия и запрет понижения.
- Отчёт скрыт за отдельной кнопкой, чтобы не мешать установке. Его можно скопировать.
- После возвращения мастер проверяет доступность экрана автоматизаций. Сохранение файла само по себе не считается успешной установкой.

## Если Task Center уже работает

Обновите только наше приложение, установив APK 3.2 поверх предыдущей версии. Повторно устанавливать или откатывать «Безопасность» не нужно. Если компонент уже доступен, нажмите «Открыть Task Center».

## Установка на Xiaomi 14

1. Скачайте и установите **Task-Center-Installer-3.2.apk**. Если Android спросит разрешение установки для браузера или файлового приложения, разрешите его и повторите открытие APK.
2. Откройте **Task Center** в основном пространстве телефона.
3. Нажмите **«Скачать APK для ручной установки»** и прочитайте предупреждение. Обновится всё приложение «Безопасность» до китайской версии 12.8.3; язык, настройки и другие функции могут измениться.
4. Дождитесь скачивания и проверки компонента. Нужны интернет, доступ к GitHub и свободное место; компонент занимает около 70 МБ, при подготовке создаются дополнительные копии.
5. В системном окне сохранения **самостоятельно выберите папку «Загрузки»** и сохраните `Security-Xiaomi-12.8.3.apk`. Приложение не выбирает эту папку автоматически.
6. Откройте **штатный «Проводник» Xiaomi → «Загрузки»**, найдите сохранённый APK и нажмите на него. Если сохранили в другую папку, откройте её. При запросе разрешите установку из этого файлового приложения.
7. Подтвердите обновление «Безопасности» и дождитесь **App installed / Приложение установлено**. Этот способ ещё не гарантирует успех на каждой прошивке.
8. Вернитесь в **Task Center → «Открыть Task Center»**. Должен открыться экран **Automated tasks**.
9. При необходимости нажмите **«Добавить ярлык на рабочий стол»**. На экране автоматизаций кнопка **«+»** создаёт задачу, **My tasks** показывает список задач.

Разрешать самому Task Center установку неизвестных приложений для ручного сохранения не требуется.

## Другие модели и ошибки

- **Нет подходящего компонента:** нажмите «Обновить каталог», затем «Скопировать отчёт». Совпадения только Android 16 или названия семейства Xiaomi недостаточно для обычного подбора. Каталог использует точные правила.
- **HyperOS запретил установку:** нажмите «Сохранить APK в „Загрузки“» и выполните ручные шаги выше. Если кэш удалён системой, потребуется повторное скачивание. В версии 3.1 сохранённого файла могло не остаться.
- **App not installed при ручной установке:** это не успех. Передайте скриншот и отчёт Task Center. Отчёт нашего приложения не получает подробный результат установки, запущенной отдельно из «Проводника»; он может содержать предыдущую ошибку.
- **Незавершённая сессия:** если системное подтверждение потерялось, нажмите «Отменить незавершённую сессию» и повторите попытку.
- **Нет значка на рабочем столе:** найдите Task Center в списке приложений и перенесите его на рабочий стол либо используйте кнопку добавления ярлыка.
- **Нужно вернуться в мастер:** удерживайте значок Task Center → «Настройка и откат». Пока отчёт не скопирован, приложение может открывать мастер вместо прямого запуска автоматизаций.

Отчёт хранится локально и не отправляется автоматически. Перед отправкой можно просмотреть его кнопкой «Показать отчёт установки».

## Откат

1. Откройте **Task Center → «Открыть настройки для отката»**. Если значок сразу открывает автоматизации, удерживайте его → **«Настройка и откат»**.
2. В карточке **«Безопасности»** найдите **«Удалить обновления» / Uninstall updates** — внизу экрана или в меню ⋮.
3. Прочитайте системное подтверждение и подтвердите откат, если согласны.

Вернётся версия **из прошивки**, а не обязательно версия перед установкой. Настройки «Безопасности» и задачи могут сброситься, Automated tasks может исчезнуть. Не нажимайте «Очистить данные» или «Удалить приложение». Если удаления обновлений нет, этот мастер не предоставляет автоматического обхода.

Удаление самого Task Center **не откатывает** «Безопасность».
