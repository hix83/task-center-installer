# Проверки версии 3.0

- Сборка из исходников, выравнивание APK и проверка подписи Android SDK apksigner — пройдены.
- В APK отсутствует `assets/security.apk`; включён подписанный каталог.
- 9 сценариев CatalogPolicyTest — пройдены, включая неизвестную модель, Android, сборку, исходную версию и запрет понижения.
- Инструментальные тесты на Xiaomi 15T Pro / Android 17 — пройдены: проверка подписи каталога, отказ при подмене, ограничения URL, выбор записи для известной исходной конфигурации.
- Реальное скачивание отдельного 70-МБ компонента через код Android-приложения — пройдено. Совпали размер, SHA-256, пакет, версия и сертификат Xiaomi. Скачанный тестовый файл удалён, компонент тестом не устанавливался.
- Опубликованный каталог скачан отдельно с raw.githubusercontent.com; совпадает с проверенным на телефоне файлом, RSA/SHA-256 подпись проверена OpenSSL.
- Экран готовности с кнопками создания ярлыка, обновления каталога и копирования диагностики осмотрен на 15T Pro. Финальная сборка установлена в основной профиль телефона.

Оставшиеся проверки:
- Полный цикл «глобальная версия → скачивание через мастер 3.0 → системная установка» не повторялся. Установка того же компонента через системный установщик из мастера 2.1 ранее успешно проверена.
- Сохранение обновлённого сетевого каталога через интерфейс приложения и подтверждение нового закреплённого ярлыка пока не проверены полностью на устройстве.
- Xiaomi 14 и другие модели вне каталога не проверены. Срабатывание автоматизаций и длительная стабильность не проверены.
